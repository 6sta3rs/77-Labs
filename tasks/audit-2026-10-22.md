# Audit task list, 22 October 2026

Regression checklist and history for the 31 tasks of the 22 October 2026 audit. They were implemented in commit `71043fc` and released as 0.2.2 (verification: `docs/progress.md`, entry "audit task list implemented and verified"). Open work is tracked in `BOARD.md` (T-0021 to T-0024).

How to read a task: **status**, **how verified** (see below), **files** (from the audit list; `(inferred)` marks files the list did not name and that were taken from the diff of `71043fc`), **automated checks** that cover it, and **steps in the app**.

The automated-check lists were mapped by area and file name for this document; they were not re-run for it, and a listed check may not assert the exact behaviour. Treat them as the place to look first.

Verification levels: **APP** = checked in the running app with the real engine; **TEST** = checked in code and by automated tests, not in the app window; **CODE** = read in code only.

## How to test

Every change, whatever the task (the gate from `AGENTS.md`):

1. `npm run check`, `npm run build`, `npm run test:ui`, `npm run test:structure`.
2. Rust changed: `cargo check --manifest-path src-tauri/Cargo.toml`.
3. Python backend changed: `python -B tools/dev/test_runtime.py` with the private venv (`%LOCALAPPDATA%\VoiceStudioNext\runtime\.venv`); the full tests need FFmpeg and MCP, they do not download models or run inference.
4. Documentation: `docs/progress.md` entry with what was checked and what was not; `git diff --check`.

In the app (a build or health response alone does not prove a feature):

1. `npm run desktop:build` (EXE: `src-tauri/target/release/seventy-seven-labs.exe`) or install from `npm run desktop:release`.
2. Start it with isolated data and the WebView2 remote debugging port, the way `tests/acceptance/settings_desktop_acceptance.py` and `tests/acceptance/cpu_installer_acceptance.py` do (`WEBVIEW2_USER_DATA_FOLDER`, `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=<port> --remote-debugging-address=127.0.0.1`, new `LOCALAPPDATA`). Do not touch the old VoiceStudio installation or its database.
3. Drive and inspect the window over CDP (evaluate an expression, take a screenshot). Screenshots and logs go to the ignored `.tmp/qa/T-NNNN/`, never into git.
4. A cold engine start takes about 1.5 minutes before the model preload begins on a slow disk; wait for `/health` and `/model/status` instead of sleeping.
5. Do not run real generation unless the task needs it; state in `docs/progress.md` what was not verified.
